# BP — ระบบบันทึกความดันโลหิต

[English](README.md) | **ภาษาไทย**

เว็บแอปสำหรับบันทึกและติดตามความดันโลหิตและค่าสุขภาพพื้นฐานของบุคคล ครอบครัว
และกลุ่มในชุมชน ออกแบบให้ อสม. และผู้ดูแลในครอบครัวใช้งานได้ แม้ไม่มีอินเทอร์เน็ต

พัฒนาบน [Now.js](https://www.nowjs.net) (ฝั่งหน้าเว็บ) และ
[Kotchasan](https://www.kotchasan.com) (ฝั่ง PHP)

## ความสามารถ

- **บันทึกค่าตรวจวัด**: ความดันตัวบน/ตัวล่าง ชีพจร น้ำหนัก ส่วนสูง อุณหภูมิ
  รอบเอว น้ำตาลในเลือด และ SpO₂ พร้อมหมายเหตุและแท็ก
- **ครอบครัวและกลุ่ม**: จัดการสมาชิกและจัดเป็นกลุ่ม (หมู่บ้าน หมู่ ที่อยู่ พิกัด)
- **เยี่ยมบ้าน**: ผูกค่าที่วัดกับการเยี่ยม
- **แดชบอร์ดการดูแล**: ดูว่าใครความดันสูง ใครควรส่งต่อ และใครไม่ได้วัดเกิน 30 วัน
- **ประวัติและรายงาน**: ประวัติรายบุคคล ค่าเฉลี่ยตามจำนวนวันที่กำหนด และส่งออกข้อมูล
- **ปรับเกณฑ์ได้**: ระดับปกติ สูง และส่งต่อ
- **PWA ใช้งานออฟไลน์**: บันทึกตอนไม่มีเน็ตแล้วซิงค์ภายหลัง แต่ละรายการมี
  `client_uuid` จากอุปกรณ์ ส่งซ้ำก็ไม่เกิดข้อมูลซ้ำ
- **การแจ้งเตือน**: บอท LINE และ Telegram อีเมล (PHPMailer) และ SMS
- **เครื่องมือผู้ดูแล**: จัดการผู้ใช้และสิทธิ์ เข้าสู่ระบบด้วย Google/Facebook
  ล็อกเมื่อใส่รหัสผิดเกินกำหนด ภาษาไทย/อังกฤษ เทมเพลตอีเมล หมวดหมู่ และผู้ช่วย AI (ไม่บังคับ)

## ความต้องการของระบบ

- PHP **7.4** ขึ้นไป
- MySQL 5.5.3+ หรือ MariaDB 5.5+ (utf8mb4)
- Apache พร้อม `mod_rewrite` และเปิดใช้ `.htaccess` (ใช้ Nginx ได้ด้วยกฎ rewrite ที่เทียบเท่า)
- แนะนำ HTTPS และจำเป็นถ้าต้องการติดตั้งเป็น PWA

## การติดตั้ง

1. คัดลอกโปรเจ็คไปไว้ใน web root
2. ให้เว็บเซิร์ฟเวอร์เขียนโฟลเดอร์ `settings/` และ `datas/` ได้
3. เปิด `http://your-host/install/` แล้วทำตามขั้นตอน: ตรวจระบบ ตั้งค่าฐานข้อมูล สร้างบัญชีผู้ดูแล
4. เมื่อติดตั้งเสร็จ ให้ลบหรือป้องกันโฟลเดอร์ `install/`
5. เข้าสู่ระบบด้วยบัญชีผู้ดูแลที่สร้างไว้

### การปรับรุ่น

1. **สำรองฐานข้อมูลและโฟลเดอร์ `settings/` `datas/` ก่อนเสมอ**
2. แทนที่โค้ดใหม่ โดยเก็บ `settings/` และ `datas/` ไว้
3. เปิด `/install/` อีกครั้ง ระบบจะตรวจพบรุ่นเก่าและปรับรุ่นให้

ปรับรุ่นผ่านบรรทัดคำสั่งดู [install/cli-upgrade.php](install/cli-upgrade.php)

## การตั้งค่า

ค่าตั้งอยู่ใน `settings/config.php` และ `settings/database.php` ซึ่งตัวติดตั้งสร้างให้
และ **ไม่ถูก commit เข้า git** ส่วนใหญ่แก้ได้ในเมนู *ตั้งค่า* เกณฑ์ความดันใช้คีย์ `bp_*`:

| คีย์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `bp_sys_max` / `bp_dia_max` | 120 / 80 | ขอบบนของค่าปกติ |
| `bp_sys_hight` / `bp_dia_hight` | 140 / 90 | สูง |
| `bp_referral_sys` / `bp_referral_dia` | 180 / 110 | ส่งต่อสถานพยาบาล |
| `bp_avg_days` | 7 | จำนวนวันที่ใช้หาค่าเฉลี่ย |
| `bp_sync_enabled` | true | เปิดซิงค์ออฟไลน์ |

LINE, Telegram, SMS, อีเมล, AI และ Google/Facebook login ตั้งค่าในหน้าผู้ดูแล
webhook อยู่ที่ [line/webhook.php](line/webhook.php) และ [telegram/webhook.php](telegram/webhook.php)

## โครงสร้างโปรเจ็ค

```
modules/bp/        โมดูล BP: controllers (API), models, SQL
modules/index/     ผู้ใช้ การยืนยันตัวตน การตั้งค่า ภาษา
templates/         หน้า HTML (templates/bp คือหน้าของ BP)
language/          คำแปล en / th
Gcms/              คลาสพื้นฐานร่วม (API, DB, อีเมล, LINE, Telegram, AI)
Kotchasan/         เฟรมเวิร์ก PHP
Now/               เฟรมเวิร์ก Now.js (ซอร์สใน Now/js, ไฟล์บิลด์ใน Now/dist)
install/           ตัวติดตั้ง ตัวปรับรุ่น และเครื่องมือ CLI
```

API อยู่ใต้ `api/bp/*` เช่น `api/bp/record/save`, `api/bp/history`, `api/bp/care`

## การบิลด์ฝั่งหน้าเว็บ

จำเป็นเมื่อแก้ไฟล์ใน `Now/js` หรือ `Now/css` เท่านั้น (ไฟล์ใน `Now/dist` ถูก commit ไว้แล้ว)

```bash
npm install
npm run build
npm test
```

## ข้อควรระวังทางการแพทย์

BP เป็นเครื่องมือช่วยบันทึกและคัดกรองเบื้องต้น **ไม่ใช่การวินิจฉัย** และไม่แทนคำแนะนำของแพทย์
หากมีอาการผิดปกติหรือค่าสูงมาก ให้พบแพทย์ เกณฑ์เริ่มต้นเป็นแนวทางทั่วไป
โปรดตรวจสอบกับแนวทางเวชปฏิบัติในพื้นที่ของท่าน

## ความเป็นส่วนตัว

แอปเก็บข้อมูลสุขภาพส่วนบุคคล ผู้นำไปใช้ต้องรับผิดชอบเรื่องการขอความยินยอม การควบคุมสิทธิ์
การสำรองข้อมูล และกฎหมาย เช่น PDPA ควรใช้ HTTPS ตั้งรหัสผ่านผู้ดูแลให้แข็งแรง
และจำกัดการเข้าถึง `settings/` และ `datas/`
