# Security Policy

This app handles personal health data. Please report vulnerabilities
**privately** — do not open a public issue.

- Use GitHub's "Report a vulnerability" (Security tab) on
  https://github.com/goragodwiriya/bp, or email admin@goragod.com.
- Include steps to reproduce, affected version and impact.

You can expect an acknowledgement within a few days. Please allow time for a
fix before public disclosure.

Only the latest release receives security fixes.
